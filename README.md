# Программа «Маклер»

Приложение для учёта заявок на обмен квартир и поиска взаимных вариантов обмена.

## Функции по заданию

- ввод заявки с данными желаемой и имеющейся квартиры;
- поиск взаимного соответствия в картотеке;
- вывод найденной заявки и удаление обеих активных заявок при совпадении;
- добавление новой заявки в картотеку, если совпадение не найдено;
- просмотр всей активной картотеки.

Для каждой квартиры сохраняются количество комнат, площадь, этаж и район. Совпадение определяется по точному количеству комнат и этажу, а площадь может отличаться не более чем на 10%. Район сохраняется и отображается, но не участвует в базовом критерии совпадения. Активная картотека обрабатывается как Python-список `list`.

Дополнительно ведётся история завершённых обменов: при удалении активных заявок сведения о двух заявках сохраняются в виде снимка.

## Запуск

Требуется Python 3.12+ и `uv`.

```bash
uv sync
uv run makler
```

База SQLite создаётся автоматически в `~/.makler/makler.sqlite3`.

## Проверки

```bash
uv run pytest
uv run ruff check .
```

## Технологии

- Python 3.12+
